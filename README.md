# Student-Marks-Calculator
A simple Java program to calculate student total marks,percentage and grade
0Student Marks Calculator 🎓

A simple Java project that calculates students' total marks, percentage, and grade based on marks entered for five subjects.

📌 Project Overview

The Student Marks Calculator is a beginner-friendly Java application developed to practice programming fundamentals, loops, conditional statements, and basic mathematical calculations.

✨ Features

- Accepts marks for five subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade based on percentage
- Validates marks between 0 and 100

🛠️ Technologies Used

- Programming Language: Java
- Concepts: Loops, conditional statements, arithmetic operations, and user input

💻 How to Run

1. Install the Java Development Kit (JDK).

2. Download "StudentMarksCalculator.java".

3. Open Command Prompt in the folder containing the file.

4. Compile the program:
   
   javac StudentMarksCalculator.java

5. Run the program:
   
   java StudentMarksCalculator

📊 Sample Input

Enter marks in 5 subjects:
80 90 70 85 75

✅ Sample Output

Total Marks: 400
Percentage: 80.0%
Grade: B
